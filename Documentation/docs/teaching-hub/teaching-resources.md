# Teaching resources

This page distinguishes resources that are usable now from curriculum components that are specified but still require development or validation.

## Current practical guides

These substantial guides already exist in the live documentation:

| Practical resource | Focus |
|---|---|
| [First experiment](../quickstart/first-experiment.md) | Connect, stimulate and observe a first response |
| [Patch-clamp-style investigations](../experiments/patch-clamp-style-labs.md) | Current-clamp and bounded voltage-clamp analogies |

## Curriculum architecture

The [80-module catalogue](modules/index.md) provides concept statements, audiences, logistics, learning outcomes, activity roadmaps, reusable outputs, dependencies, evidence sources and explicit scientific boundaries.

- [View the editable curriculum source](https://docs.google.com/document/d/1r0rBCIA8rZh-NVbDUveSH7BIDQevo0SJ_z3V8vJnxHs/view)
- [Make your own copy of the curriculum source](https://docs.google.com/document/d/1r0rBCIA8rZh-NVbDUveSH7BIDQevo0SJ_z3V8vJnxHs/copy)

The MkDocs pages are the primary public reading experience. The editable source is retained for educators who want to adapt the architecture.
