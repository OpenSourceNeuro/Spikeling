# **Changelog**

This changelog documents user-visible changes in Spikeling across hardware, firmware, and GUI releases.

- **Added**: new features
- **Changed**: changes in behavior or defaults
- **Fixed**: bug fixes
- **Deprecated**: features planned for removal
- **Removed**: removed features
- **Security**: security-related changes
